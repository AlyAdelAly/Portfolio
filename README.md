# Portfolio

My personal portfolio site — a single-page, dark/terminal-themed site built with plain HTML & CSS, showcasing my experience, projects, and skills as a Frontend Engineer.

🔗 **Live site:** https://alyadelaly.github.io/Portfolio/

## About

This portfolio highlights my work across React, Next.js, Vue, and Tailwind CSS, along with growing full-stack experience in Python and Django. It includes:

- **Experience** — a timeline of my roles at CyberDefenders, Algoriza, White Account, and Branspect
- **Projects** — featured work including a cybersecurity training platform, an educational platform for kids, an internal ERP portal, and more
- **Skills** — languages, frameworks, backend, state management, and tools
- **Education** — B.Sc. in Software Engineering, Ain Shams University

## Tech

- HTML5 / CSS3 (no frameworks or build step)
- Fonts: [JetBrains Mono](https://www.jetbrains.com/lp/mono/) & [Inter](https://rsms.me/inter/)

## Running locally

This is a static site — just clone and open `index.html` in your browser:

```bash
git clone https://github.com/AlyAdelAly/Portfolio.git
cd Portfolio
open index.html
```
